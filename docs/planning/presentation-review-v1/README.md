## 파일

- **hanklasse-presentation-reviewed.pptx**: 통합 PPT 한 파일. 본편 p1~p40 각각 1슬라이드 + 부록 A1·A2·B·C·D, 총 45장. 장별 개별 PPT 파일은 만들지 않았습니다.
- **hanklasse-presentation-reviewed.pdf**: 같은 슬라이드의 미리보기.
- **page-review.md / page-review.csv**: 페이지별 수정 이유·검증 상태·발표 메모·출처.
- **source-register.csv**: 전체 근거 URL·확인 상태·주장을 뒷받침하는 범위.
- **slide-overview.png**: 전체 슬라이드 한눈에 보기.
- **verification-summary.txt**: 코드·테스트·자료 검증 범위.

PPT 텍스트·도형은 편집 가능하며, 실제 코드 캡처만 이미지입니다.
PowerPoint의 ‘보기 → 슬라이드 노트/메모’에서 각 장의 발표·수정·근거 메모를 확인하세요.
슬라이드 아래 자료명에는 출처 링크가 있고, 원문이 제공되지 않은 강의자료는 출처명만 적었습니다.

## 가장 중요한 한계

1. 원고의 evidence.md·lecture-notes.md는 이번 첨부와 공개 저장소에서 찾지 못했습니다.
2. 기사·통계·논문·법령 사이트는 네트워크 접근이 차단돼 원문을 재검증하지 못했습니다. 숫자가 틀렸다고 확정한 것은 아닙니다. 미검증 수치는 본문에서 단정하지 않고 검토표에 보류했습니다.
3. 추가 공식 근거 5건은 Supabase·Google·GitHub의 기술문서입니다. 시장 수요·가격 적정성·학습 효과를 증명하는 자료가 아닙니다.
4. 저장소 ba055b9 기준으로 278개 테스트·빌드·강좌 규칙 검사를 직접 실행했습니다. 서버 연결 완료는 CHANGELOG 기록이며, 실제 로그인·다른 기기·원격 권한을 이번에 다시 검증하지는 않았습니다.
5. 영상·실습 파일·GA4는 준비 중입니다. 데모 신청과 실제 결제, 자기보고 체크와 실제 학습 성과를 구분했습니다.
6. 개인 경험·발표자 이름·인터뷰·손익 가정은 본인이 확인한 내용으로 채워야 합니다. 허구로 보충하지 않았습니다.

## 사용 전

원문이 확보되면 page-review의 보류 항목부터 재검토하세요. 발표 직전 최신 사이트 상태를 확인하고 시연을 녹화하세요.
전체 40장 진행 또는 선택 9장을 생략한 31장 진행 중 하나로 리허설해 30분 안에 맞추세요. 부록은 질문 때만 사용합니다.
사이트 소스·main 브랜치·배포는 이 검토 작업에서 수정하지 않았습니다.
