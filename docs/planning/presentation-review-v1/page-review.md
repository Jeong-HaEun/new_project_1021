1. 가격: 500원부터 → 1,000~2,000원.
2. 서로 다른 설문의 74.6%와 12.7% 직접 비교 막대 삭제.
3. 취업 준비 비용으로 1,000원 가격 타당성을 바로 도출하지 않음.
