# 한클래스 메인 A/B — 감성 몰입형 vs 정보 탐색형

## 이 요청이 기준

이 문서는 이전 ‘카드 제목 vs 결과물 위계’ 실험을 대체한다. 두 실험을 동시에 구현하지 않는다.
우리 목적은 통계적 승자보다 문제·가설·화면·배정·계측·검증을 설계할 수 있음을 포트폴리오로 보여주는 것이다.
기존 한클래스 저장소는 구현 담당 세션 하나만 수정한다. git 상태·CLAUDE.md·디자인·관련 파일을 먼저 확인하고 기존 작업은 보존한다.
수정 전 짧게 계획을 알리고, 충돌·예상 밖 변경이 있으면 멈추고 보고한다. 커밋·푸시는 승인 후 진행한다.

## 전달 파일

- index.html + prototype.css + prototype.js + courses-data.js: 실제로 전환·검색할 수 있는 독립 시안.
- A/B-desktop.png, A/B-mobile.png: 첫 화면 캡처. full 버전은 아래 공통 구성까지 참고.
- assets/hero-art.webp: 제작한 감성형 배경 원본의 웹용 파일(약 380KB, 1536×1024).
- assets/hero-art-original.png: AI로 제작한 원본. 실제 사이트는 WebP 사용.
- 기획안 PDF: 화면 의도·비교 범위·측정·인수 기준.

기존 사이트에 index.html을 통째로 덮어쓰지 말 것. 시안은 기존 Vite+Vanilla JS 구조에 맞게 컴포넌트·데이터·토큰으로 옮긴다.
시안은 프레임워크·설치 없이 브라우저에서 열어볼 수 있으며 GA4·무작위 배정·실결제는 없는 UI 데모다.
클릭 시 뜨는 dialog는 강의 구성 확인용 임시 장치다. 실제 서비스는 기존 공통 상세 페이지로 연결한다.

## 전략·가설

A 감성 몰입형: 거친 입자·콜라주가 있는 푸른 대형 이미지와 큰 문구로 ‘첫 실무 결과물을 만드는 설렘’을 전달한다.
B 정보 탐색형: 이미지 대신 짧은 소개 뒤 검색·분야·강의·가격·결과물을 첫 화면에 빠르게 보여준다.
정보를 바로 보여주면 필요한 강의를 찾는 부담이 줄어 상세 탐색이 늘어날 수 있다. 반대로 큰 비주얼이 관심·기억을 높일 수도 있다.
어느 안이 우수하다고 미리 단정하지 않는다.
이것은 ‘메인 진입 구성 전략’ 패키지 비교다. 이미지 유무·히어로 높이·정보 노출 위치·모바일 카드 밀도가 함께 달라진다.
따라서 결과를 ‘이미지 하나의 효과’로 주장하지 않는다. 세부 요인별 실험은 다음 단계다.

## 화면 규칙

공통: 브랜드·내비게이션·대표 문구·설명·가격 1,000~2,000원·구독 없음·강의 6개·분야·정렬·강의 데이터·검색 로직·상세 목적지·광고 보고서 연결 동일.
추천 학습 순서 등 기존 공통 섹션은 양쪽에서 동일하게 유지한다. 실험과 관계없는 영역은 변경하지 않는다.
강의는 제작 예정, 로그인·장바구니·커뮤니티 등은 준비 중. 실제 결제·카드정보·가짜 리뷰·성과·경력 추가 금지.

A:
- 데스크톱 대형 풀폭 히어로. 시안 기준 높이 620px 안팎이며 사이트 레이아웃에 맞게 조절.
- 흰 HTML 텍스트와 CTA는 좌측, 이미지의 오브젝트는 우측. 문구를 이미지에 구워 넣지 않는다.
- 검색·분야·강의가 뒤이어 나온다. 아래 공통 정보로 실제 이동 가능한 CTA를 제공한다.
- 모바일은 625px 안팎 이미지 영역. 텍스트 뒤에 어두운 오버레이를 두고 대비를 검증한다.
- 배경은 장식 이미지라 alt="". 의미는 화면 텍스트가 담당한다.
- 입자 효과는 이미지 안에 포함돼 있다. 실시간 노이즈·패럴랙스·자동 영상·WebGL을 추가하지 않는다.

B:
- 히어로 아트 요청 없음. 설명을 짧게 묶고 검색·분야를 곧바로 노출.
- 데스크톱은 첫 화면에서 강의 카드의 제목·결과물·가격이 보이게 한다.
- 모바일은 썸네일+정보의 가로형 컴팩트 카드로 첫 강의의 제목·결과물·가격을 확인 가능하게 한다.
- 모바일 390×844 캡처가 참고 기준. 375px에서도 넘침·텍스트 누락 없이 검증.

공통 접근성: 키보드·포커스·검색 레이블·제작 예정 고지 유지, 작은 보조 글도 읽을 수 있게 조정.
기존 디자인 토큰은 유지·확장하고 색/간격을 CSS 변수에 정리한다. 핵심 본문 대비를 검증한다.
원본 사용자 레퍼런스 이미지를 복제·게시하지 않는다. 전달된 hero-art는 새로 제작한 독립 이미지다.

## 구현 순서

1. A/B 시연 렌더링만 먼저 구현하고 검증. 사용자가 화면 확인 후 다음 단계 진행.
2. 별도 실험 모듈로 배정·버전·저장·롤백 추가.
3. GA4 어댑터/검증. 측정 ID·안내·운영 설정 확정 후 별도 승인으로 실제 수집 활성화.
현재 시안 파일을 실제 실험이 이미 구현된 것으로 보고하지 않는다.

## 실험/시연 모드

- 새 ID: hc_home_strategy_v1. 이전 카드 위계 실험과 별개.
- 운영 초기 실험 비활성: B 정보형을 기본 제공하고 실험 이벤트는 중지한다.
- 시연 링크 ?ab_preview=A/B. 시연에서만 ‘기획 시연 · 측정 제외’ 전환 바 제공.
- 시연은 배정 저장값을 덮어쓰지 않으며 내부 상세 이동까지 GA4 자동·수동 수집을 차단한다.
- 일반 모드에서 ID별 A/B 50:50 무작위 배정, 첫 렌더 전에 확정. 같은 브라우저는 같은 안을 유지.
- 기존 localStorage 실험 저장 구조를 확인하고 충돌 없이 ID별 보관. 실패 시 sessionStorage, 둘 다 실패 시 B+측정 제외.
- 브라우저 저장소 단위 배정이며 사람·계정·여러 기기의 동일성을 보장하지 않는다.
- 실험 중지 시 B+이벤트 중지. 버전 변경 시 새 ID, 기존 결과와 혼합 금지.
- 일반 페이지에는 시연 전환 바를 노출하지 않는다. 시연 캡처의 높이 차이는 QA 바가 포함됐음을 기록한다.

## 측정

주 지표: 메인에 노출된 후 같은 탭 세션에서 강의 상세로 이동한 탭 세션 수 / 메인 노출 탭 세션 수.
분모를 ‘강의 카드 노출’로 잡지 않는다. A의 카드는 아래에 있으므로 그렇게 잡으면 실제 구성 차이를 제거하는 편향이 생긴다.
메인 이벤트: document가 보이고 앱 렌더 준비 후 1초 연속 유지 시 experiment_home_exposure, ID별 탭 세션당 1회.
A 배경 이미지 로드 완료를 노출 자격 조건으로 삼지 않는다. 이미지 실패·느린 로딩은 해당 전략의 품질 문제로 별도 기록한다.
상세 이벤트: 노출 이후 홈의 강의 카드·공통 추천 학습 순서 등 실제 상세로 가는 링크 선택 시 experiment_course_open, 최초 1회.
검색 결과 페이지를 거치는 경우 experiment_id·variant·홈 유입 컨텍스트를 탭에 보관하고 첫 상세 도달에서만 기록한다.
홈 노출 없이 상세 직접 진입한 세션은 이 분자에서 제외한다. 외부 광고 보고서 링크는 별도 지표이며 상세 전환에 포함하지 않는다.
집계 단위는 sessionStorage 수명의 탭 세션. GA4의 기본 세션과 다르다. 양 이벤트에 중복 방지하고 탭 세션 기준이라고 보고한다.
속성: experiment_id, variant, mode, placement. 상세에는 course_id, source(home_card/home_path/course_list) 추가.
기존 select_item/view_item을 유지하더라도 실험 주 지표의 분자를 중복 전송하지 않는다.

보조: 강의 구역 도달(공통 #classes가 화면에 나타남), 검색 제출, 외부 보고서 열기.
A 전용 CTA 클릭을 주 지표로 삼지 않는다. 스크롤 도달·체류시간·이미지 관심을 구매 의사로 해석하지 않는다.
성능 점검: A/B LCP·레이아웃 이동·이미지 오류. 동일 기기·네트워크에서 비교. 실측 수치는 실행한 경우만 기록.
A는 이미지 크기 예약과 WebP 사용. B는 숨기는 것뿐 아니라 아트 리소스를 요청하지 않도록 렌더한다.
검색어 원문·이메일·기업/경험/자소서 입력·비밀번호는 전송하지 않는다. URL 쿼리도 자동 수집에서 제거.
GA4가 없으면 무전송, 시연은 GA4 초기화 자체를 하지 않는다. 실험 수집 전 실제 안내·동의 적용 설정을 확인한다.

## 인수 검증

- A/B 시연 주소·전환, 일반 배정 유지, 시연 후 배정 원상 유지, 기본 비활성 B.
- 카드 6개·가격·정렬·검색/필터·결과물·상세 주소가 동일.
- 375/390/768/1440px, 키보드, 모바일 메뉴·하단 데모 고지·고정 구매 영역 충돌 없음.
- A 텍스트가 배경과 겹쳐도 읽힘. 작은 글씨 대비도 확인.
- B 첫 진입에서 대형 아트 네트워크 요청 0건. A 이미지 실패해도 텍스트·CTA 작동.
- 이미지 로드가 레이아웃을 밀지 않음. reduced-motion에서는 부드러운 스크롤 중지.
- 시연·상세 이동 후 GA4 요청 0건, 이벤트 중복·홈 미노출 상세 진입 제외.
- 검색→목록→상세 경로도 실험 컨텍스트 유지. 재방문·뒤로 가기·배정 저장 손상·저장소 차단 처리.
- 실제 결제·임의 성과 차트 없음. 기존 npm test·npm run build·콘솔 확인.
