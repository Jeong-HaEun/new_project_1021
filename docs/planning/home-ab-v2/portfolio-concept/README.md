## 기획 의도

막막한 취업 준비가 작은 실무 결과물로 채워진다는 의미입니다.
표 = 엑셀 데이터 정리, 보고서 = 광고 성과 해석, 슬라이드 = PPT 전달을 나타냅니다.
상승 그래프는 가상 보고서의 시각 요소이며 실제 성과·취업 효과·보장 지표가 아닙니다.

## 제작·사용 기록

2026-10-16 AI 이미지 생성 도구로 이 기획을 위해 새로 제작했습니다. 외부 스톡 사진을 다운로드하거나 별도 라이선스를 구매하지 않았습니다.
실존 인물·기업 로고·식별 가능한 제품 화면을 포함하지 않도록 생성했습니다.
생성물이므로 권리 문제가 전혀 없다는 보증이나 공공영역/CC0 선언은 하지 않습니다. 게시 전 사용자가 최종 내용을 확인하세요.
웹용 파일은 생성 원본을 WebP로 변환한 것입니다. 원본 PNG를 함께 보관합니다.

적용 예시의 텍스트는 HTML로 따로 배치한 화면 캡처입니다. 실제 구현 시에도 글자를 배경에 합치지 말고 HTML 텍스트로 유지하세요.
큰 결과물 아트가 의미를 전달하므로 우선 정적 이미지 사용을 권장합니다. 모션을 추가한다면 별도 HTML/CSS에서 아주 작은 등장 효과만 주고 reduced-motion을 지원하세요.
실제 사이트 코드·배포는 변경하지 않았습니다.
